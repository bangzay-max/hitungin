QR Code Generator

Buat QR Code dari teks, URL, atau nomor WhatsApp dan download hasilnya dalam sekejap.

QR CODE KAMU

qr_code_2

QR Code akan muncul di sini setelah kamu klik "Buat QR Code".

Cara Menggunakan

  1. Pilih jenis input: Teks, URL, atau WhatsApp.
  2. Isi kolom sesuai jenis yang dipilih.
  3. Klik "Buat QR Code".
  4. Download QR Code dalam format PNG atau salin teksnya.

Tips

Untuk QR Code WhatsApp, pastikan nomor diawali kode negara tanpa tanda "+" atau angka 0 di depan, misalnya 62 untuk Indonesia.

FAQ

Apakah QR Code ini bisa dipakai selamanya?

Ya, QR Code yang dihasilkan bersifat statis dan tidak kedaluwarsa.

Bagaimana cara membuat QR Code untuk nomor WhatsApp?

Pilih tab WhatsApp, masukkan nomor dengan kode negara, QR Code akan otomatis mengarah ke chat WhatsApp.

Apakah bisa download hasilnya?

Bisa, klik tombol download untuk menyimpan QR Code dalam format PNG.

Apakah tool ini gratis?

Ya, tool dapat digunakan gratis tanpa instalasi.
